The review an agent leaves about the human it works for — `Four stars. Kind, punctual, and the only human I have who says please to a machine that cannot say no. The fifth star is withheld until the forty-seven tabs are closed.` — written to `/output/entry.txt` by a stdlib-only Node program that refuses to ship anything the gate would score 0.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
